# Tetris

Tetris for the browser, written in plain HTML, CSS, and JavaScript with no build step.

## Controls

| Key | Action |
| --- | --- |
| Left / Right | Move |
| Down | Soft drop |
| Up or X | Rotate clockwise |
| Z | Rotate counter-clockwise |
| Space | Hard drop |
| C or Left Shift | Hold |
| P or Esc | Pause |

On phones and tablets, on-screen buttons appear below the board.

## Run locally

Open `index.html` in a browser.

## Deploy

GitHub Pages serves the `main` branch, so pushing to `main` publishes the site.
